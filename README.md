# AIdea 중간발표 자료

AI 때문에 막힌 개발자가 먼저 푼 사람의 기록으로 문제를 해결하고, 그 기록을 MCP·플러그인으로 에이전트에 연결하는 커뮤니티 **AIdea**의 중간발표 슬라이드예요.

## 보는 법

`index.html`을 브라우저로 열면 돼요. 글꼴은 인터넷에 연결돼 있을 때 Google Fonts에서 불러와요.

| 키 | 동작 |
| --- | --- |
| → · Space · 화면 오른쪽 클릭 | 다음 슬라이드 |
| ← · 화면 왼쪽 클릭 | 이전 슬라이드 |
| N | 발표자 노트 보기/숨기기 |
| F | 전체 화면 |
| Home / End | 처음 / 끝 |

주소 끝에 `#5`를 붙이면 5번 슬라이드부터 열려요. PDF가 필요하면 브라우저 인쇄에서 'PDF로 저장'을 고르면 슬라이드 한 장이 한 쪽으로 저장돼요.

## 구성

- **본문 1~14장**: 대본을 읽으면 약 7~8분이에요.
  - 생태계 → 고객의 불편함 → 방향성 설정 → 방향성의 근거 → 비즈니스의 구체화(사업모델, 기능 설계, MVP 실험)
- **부록 15~18장**: 질의응답 때 펴는 자료예요. 부록 표지, 아직 확인하지 못한 것, 수익 단계와 조건, 데이터 신뢰 원칙으로 모두 18장이에요.
- **`발표대본.md`**: 슬라이드별 대본이에요. ‘참고:’, ‘질문 대비:’, ‘출처:’로 시작하는 줄은 읽지 않는 메모예요.

## 자료 기준

수치와 출처는 2026년 10월 19일에 확인했어요. 각 슬라이드 노트 끝의 ‘출처:’ 줄에 원문 이름과 날짜가 있어요. 설문 문항, 업체 자체 자료, 심사 전 논문 같은 조건은 슬라이드와 노트에 함께 적었어요.
